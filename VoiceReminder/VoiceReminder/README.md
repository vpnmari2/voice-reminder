# Voice Reminder
Speaks your task out loud at full alarm volume instead of playing an alarm sound.

## Build the APK
Option A - Android Studio: File > Open this folder > Build > Build APK(s).
Option B - GitHub: push this folder to a new repo > Actions tab > "Build APK" > download artifact.

## First run
1. Allow notifications.
2. Tap "Allow bypass Do Not Disturb" and enable Voice Reminder.
3. Phone settings > Battery > set Voice Reminder to "Unrestricted".
